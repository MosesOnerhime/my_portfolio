## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## 📦 Technologies

- Next.js 15
- TypeScript
- Tailwind CSS
- Lucide React (icons)

## 📁 Project Structure
```
app/
├─ globals.css    # Global styles
├─ layout.tsx     # Root layout
```
