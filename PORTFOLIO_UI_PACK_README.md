# Moses Onerhime Portfolio — UI/UX Refinement Pack

This pack is for a **careful, site-wide refinement** of the existing portfolio at:

`https://moses-onerhime-portfolio.vercel.app/`

The existing design is the baseline. The goal is **not to redesign the portfolio into a different aesthetic**. The goal is to make the current design feel more professionally resolved and more effective for recruiters, clients, collaborators, studios, and other visitors.

## Important installation note

Do **not** overwrite the project's existing `README.md`.

If the repository already has a root `AGENTS.md`, do **not** replace it. Merge the relevant instructions from `AGENTS_UI_ADDENDUM.md` into the existing file.

## Core principle

**Polish the current identity; do not replace it.**

The current site already has a strong editorial/creative portfolio direction. Codex should preserve the recognizable visual language and improve things visitors may feel subconsciously:

- scan speed;
- project prioritization;
- proof of contribution;
- case-study depth;
- navigation clarity;
- CTA clarity;
- mobile layout;
- keyboard/focus behavior;
- filtering semantics;
- content consistency;
- contact friction;
- accessibility;
- image/media performance;
- Core Web Vitals;
- metadata/social previews;
- small spacing, typography, and interaction inconsistencies.

A visual change should be justified by clarity, credibility, usability, accessibility, performance, or maintainability.

## What this pack does not authorize

It does not authorize Codex to:

- rebrand Moses;
- rename projects;
- invent project outcomes;
- invent client names;
- invent statistics;
- invent testimonials;
- invent roles or responsibilities;
- invent skills;
- remove projects just to simplify the page;
- replace the visual system with a generic portfolio template;
- add gratuitous 3D, WebGL, particle, cursor, or AI-style effects;
- commit or push without permission.
